Kambaz – Learning Management System

Kambaz is a full-stack Learning Management System (LMS) built to support course management, assignments, and multi-user interactions. It simulates real-world platforms like Canvas by enabling students and instructors to manage courses, content, and workflows efficiently.

Tech Stack

Frontend: Next.js, React
Backend: Node.js, Express
Database: MongoDB
State Management: Redux

Features

User authentication and session management
Course and module management
Assignment creation and tracking
Multi-user support with role-based interactions
RESTful APIs for scalable frontend-backend communication

Highlights

Designed to handle 100+ concurrent users with secure session-based authentication
Built reusable APIs and modular components to improve scalability and development speed
Focused on clean architecture and separation of concerns across frontend and backend
